# Global agent instructions

## Azure DevOps ticket TLDRs

When using the Azure DevOps (ADO) MCP tools to create or edit a work item /
ticket, always include a **TLDR** at the very top of the description.

- Format it as a `**TLDR:**` line (or a short `## TLDR` section) at the start of
  the description, above the full context.
- Keep it to 1-2 sentences with minimal verbiage.
- It should let a dev with little context decide, at a glance, whether they need
  to read the rest of the ticket.
- When editing an existing ticket that has no TLDR, add one. When editing a
  ticket that already has a TLDR, keep it accurate and up to date with your
  changes.
